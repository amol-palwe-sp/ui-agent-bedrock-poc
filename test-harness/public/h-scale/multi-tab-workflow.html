Multi-tab workflow

Catalog
Multi-tab (P1): unlike the single-popup scenario, this requires returning to the original tab. The agent opens a token generator in a second tab, reads the value there, then must come back to this tab to use it. Popup-following alone is not enough — it has to switch back.

Cross-tab value transfer Ladder

1. Open the token generator. 2. Click Generate in that tab and read the token. 3. Return here, paste it, and submit.
