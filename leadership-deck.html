The Challenge
Problem Statement

The Identity Coverage Gap

Thousands of enterprise applications sit outside API-based governance — invisible to SailPoint ISC

  • Legacy web portals — no REST APIs, no connectors, no governance
  • Manual provisioning — IT teams hand-craft each user create and disable request
  • Audit gaps — account changes happen entirely outside SailPoint's visibility
  • Scaling pain — each new application requires months of custom connector work
💡
The Insight
If a human can navigate a browser UI to manage identities, so can an AI agent — guided by a one-time screen recording.
🎯
The Goal
A zero-code ISC connector for any web application — just record the workflow, review it, and govern at scale.

🖼️
Frame Extraction

Step 3
🧠
AI Analysis
Bedrock Vision LLM

Step 6

Script Hydration

Step 7
🤖
AI Agent Loop
Observe → Decide → Act
Bedrock + Playwright agent navigates the live app — capturing screenshots, reasoning, and executing
Step 8
✅
ISC Confirmed
Result reported back

Agent Runtime
Under the Hood

The Observe → Decide → Act Loop

Every execution step follows the same three-phase AI reasoning cycle — continuously until the task is complete

Agent Loop (repeats per action)
📸
Observe
Live browser screenshot
Playwright captures the current browser screenshot and passes it to the LLM
🧠
Decide
Bedrock LLM reasons
Amazon Bedrock Claude views the screenshot and decides the best next action
⚡
Act
Playwright executes
Playwright performs the action: click, type, navigate, scroll, or wait
🖥️
Real Browser, Real UI
Playwright drives a real browser — no fragile CSS selectors, no custom parsing. The agent sees exactly what a human sees.
👁️
Vision-Based Reasoning
Amazon Bedrock's multimodal LLM understands page layout, form labels, and button states — no app-specific training required.
🛡️
Self-Correcting
If a step fails or the UI changes, the agent re-observes and adapts — unlike static scripts that break on UI updates.
