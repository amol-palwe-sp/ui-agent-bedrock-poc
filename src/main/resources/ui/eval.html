3 Metric Reference
Step Recall (30%)
GT steps found in output / total GT steps. Low = missing steps.
Step Precision (20%)
Output steps matching GT / total output steps. Low = hallucinated steps.
Step Order (15%)
Kendall Tau normalized. 1.0 = perfect order.
Label Accuracy (15%)
Average fuzzy similarity between matched GT/output step pairs.
Placeholder (10%)
1.0 if no credential leaks in PLACEHOLDER mode, else 0.0.
Pagination (10%)
Type + selector + description accuracy for AGGREGATION. 0 for PROVISIONING.

Pass threshold: overall score ≥ 0.70  |  LLM judge scores: 0–10 (higher = better)  |  Hallucination score: 10 = zero hallucinations
